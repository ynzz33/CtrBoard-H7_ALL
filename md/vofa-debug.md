# 普通 VOFA 调试

2026-10-09已移除独立策略追踪及USB关节/宿主策略协议。普通JustFloat由`task/vofa_debug.c`打包，经`bsp/Vofa_send.c`发送。2026-10-10起由现有defaultTask的后台服务调用。

普通帧39个float，连同4字节帧尾共160字节。默认发送到机器表指定的UART；电机失能且上一帧发送完成后，`vofa_transport.requested=0`切到USB CDC，写1返回UART。USB接收不再解析电机命令。

默认100Hz（config/machine_config.h::MACHINE_VOFA_PERIOD_MS=10），首次可发立即提交；后续距上次成功提交至少10ms。传输忙时在复制和打包前返回，不缓存、不补发、不更新成功时间；恢复后发送当前最新状态。提交失败也不推进节流时间。所需字段先在短临界区复制到私有调试快照，再在临界区外打包。传输切换和发送仅由后台服务管理，切换许可与失能状态在同一临界区核验。

| 通道 | 内容 |
| --- | --- |
| 0 | IMU、遥控、DM和DJI在线掩码 |
| 1 | 使能、跌倒、腿有效及RL/LQR投入位 |
| 2 | 故障掩码 |
| 3～12 | LQR实测状态 |
| 13～22 | LQR目标状态 |
| 23 | 前向加速度 |
| 24～25 | 左右重力补偿摆矩 |
| 26～27 | 左右世界腿角 |
| 28～31 | 最终四髋命令 |
| 32～35 | 四髋反馈力矩 |
| 36～37 | 左右实测腿长 |
| 38 | 补偿有效、台架、夹取及饱和位 |

`air_param.vofa_page`开启时，24～38切到离地检测页，字段见[air-detection.md](air-detection.md)。补偿诊断见[gravity-comp.md](gravity-comp.md)。采集依赖普通VOFA工具，不再生成策略追踪帧或提供专用追踪采集脚本。
