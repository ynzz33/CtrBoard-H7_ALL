### 2.2 控制链路（全部在 `actuationTask` @1 kHz）

```
imu_state / leg_l / leg_r / motor_state / DR16 快照        （只读，单写者模型不变）
        │
  ① LQR_Target_Update()     遥控 → target[10]，腿长目标按速率积分
  ② LQR_State_Update()      x[10]：姿态 + 腿摆角世界系 + 轮速运动学速度 + 位移积分
  ③ LQR_Control_Update()    腿长变化 >0.5mm 求值 40 个增益 → u[i] = Σ K[i][j]·(target[j] − x[j])
  ④ Leg_Balance_Compute()   腿长/防劈叉/横滚 PID → F；Leg_Force_Map_Forward(F, Tp) → 前后髋
                            → torque_output_t（输出极性在驱动边界处理）
  ⑤ Dm_Send_Torque() + Dji_Send_Wheel_Torque()
```

### 2.3 状态与输出定义（与 MATLAB 模型严格对齐）

| 索引 | 符号 | 来源 |
|:---:|---|---|
| 0 | s | `∫ ds·dt`，速度指令非 0 时清零 |
| 1 | ds | 轮速运动学 + 低通：`ω_轮·R_w + L·dθ·cosθ + dL·sinθ` |
| 2 | φ | IMU 偏航角（**不参与控制**，与参考一致） |
| 3 | dφ | IMU 偏航角速度 + 低通 |
| 4/5 | θ_ll / dθ_ll | `−leg_l.virtual_leg_angle + pitch` / `−d_virtual_leg_angle + omg_pitch` |
| 6/7 | θ_lr / dθ_lr | 同上，右腿 |
| 8/9 | θ_b / dθ_b | IMU 俯仰角 / 俯仰角速度 + 低通 |

输出 `u = [T_wl, T_wr, T_bl, T_br]`；`T_b*` 即虚拟髋扭矩 Tp。

`lqr_debug` 只供调试器 Watch 修改，不占 VOFA 通道。`wheel_enable`、`hip_enable`、`len_pid_enable` 分别门控轮、髋和腿长 PID 的最终输出；关闭时 PID 仍继续计算。`trq_max_wheel` / `trq_max_hip` 控制两级限幅。

## 三、为什么不需要移植 `Leg_Tougue`

两者数学上是同一个东西（虚功原理 `τ = Jᵀ·[F; T]`），差别只在"雅可比从哪来"：

| | MATLAB 生成的 `Leg_Tougue.c` | 本工程 `force_map` |
|---|---|---|
| 输入 | `(F, Tp, φ1, φ4)`，要自己加 +π 零位和 offset | 已解算好的 `leg_jac`，内部已处理 mirror 与三个 offset |
| 开销 | 每次调用重算五连杆几何（cos/sin/sqrt） | 解算的副产品，力映射只做 6 次乘加 |
| 风险 | 独立实现，**零位与左右镜像要重新对** | 复用已上机验证的几何链 |

`Leg_Force_Map_Forward(&leg, F, Tp, out)` → `out[0]` 前髋、`out[1]` 后髋。

### 3.1 数值核验结果（已做）

用 Python 把两边各自实现一遍，在腿长 0.13~0.23 m 的 **4413 个姿态 × 7 组 (F,Tp) = 30891 个样本**上比对：

| 对应关系 | max 相对误差 |
|---|---|
| `Leg_Tougue(F, **−Tp**)` ↔ 本工程 `force_map(F, Tp)` | **1.4e−13**（纯浮点舍入） |
| 输出通道 | `out[0] ↔ 前髋`、`out[1] ↔ 后髋`，**不换序** |
| `Leg_Position` vs 本工程解算的腿长/腿角 | 5e−15 / 3e−14（同源） |
| `Leg_Speed` vs `leg_jac·v` | 2e−15 |

**结论：几何、F 通道（F>0 = 伸腿）、输出通道全部等价；唯一差异是 `Tp` 反号。**

原因是两边腿摆角的零位定义相反：

| | 定义 | 方向 |
|---|---|---|
| 本工程 | `virtual_leg_angle = π/2 − ψ_abs + offset_phi0` | 前摆为正 |
| 参考 | `leg.ang = ψ_abs − π/2` | 前摆为负（其 `−0.05` 目标注释为"微前倾"） |

两边都在腿竖直时读 0，但符号相反。**这就带出两个必须成对处理的取反**（已实现）：

1. **状态取反**：`x[θ_ll] = −virtual_leg_angle + pitch`（角速度同理）。注意是**整体取反后再加 pitch**，不是只反腿角项——否则 `+pitch` 不跟着反，θ_ll 行会多出一个符号错的俯仰耦合项，而且常数目标 −0.05 会推向错误方向。
2. **髋扭矩取反**：`Tp = −(u[T_BL] + 防劈叉)` 之后再进力映射。因为广义力与坐标反号，且 `Leg_Force_Map_Forward(F,Tp) ≡ Leg_Tougue(F,−Tp)`。

轮扭矩与 `F` 不需要任何取反。

### 3.2 右腿处理（已数值确认）

本工程右侧 4 个 DM 的反馈已在 `dm.c` 驱动层统一取反到逻辑坐标系，`leg_solver` 的 `mirror` 保持 +1 不再镜像 → `leg_solver` 只是 `(qf,qb)` 的函数，两腿得到的是同一套逻辑坐标下的雅可比。

**因此右腿不需要参考那两步补丁（Tp 取反 + 输出序号互换），左右对称处理正确。** 参考之所以要那两步，是因为它**不在驱动层镜像**，把镜像拆散到了状态层/控制层（`leg.c` 取反腿角、`leg_ctrl.c` 取反 Tp + 换序号、`Body.c` 逆映射再取反）。把我们已镜像过的反馈再套参考的补丁 = 镜像两次 ⇒ 符号反 + 力矩送错电机。

旁证：本工程 RL 路径（`rl_torque.c` / `task_policy.c`）对右腿也是对称处理，且这条路径做过手动遥操验证。

**前提复核（1 分钟）**：把两腿摆成镜像对称姿态，读数应是 `hip_f_l ≈ hip_f_r`、`hip_b_l ≈ hip_b_r`（差值在 offset 标定范围内）。若出现 `hip_f_l ≈ hip_b_r` 这种交叉，说明左右安装不是纯镜像，零位标定要重做。

## 四、与 RL 的解耦

- LQR 与 RL 控制逻辑彼此不直接调用；公共周期与共享状态由任务层统一提供。
- 唯一交汇点是 `task_actuation.c` 的策略分支。
- LQR 模式不检查 `action_state.base_action_locked`（那是遥操的锁存），改查 `imu_state.online && leg_l.valid && leg_r.valid`。
- **不做自动降级**：LQR 条件不满足直接走零力矩分支，不偷偷切回别的策略。
- 手动遥操分支代码**一行未改**。

## 六、台架验证顺序（任何一步不过就停）

```
① 只看数据：调试器 `torque_output_enabled=0`，s1 中位。看 ch1 bit2/3 两腿有效、bit4~7 四台使能；ch10/14 腿长 ≥0.13。然后把下面四项符号/零点定下来，全部对上再进 ②：
  ①a 腿摆角零位：腿竖直（轮轴在髋轴正下方，用铅垂线比）时看 ch9/ch13，应 ≈0。不为 0 就把 `machine_config.c` 小机器表的 `leg_off_phi0` 改成实测差值；现值 −0.13/−0.07 是大机器换算值抄来的，Leg2 为 0。
  ①b IMU 轴与极性：本机 `euler_rad[0]` 装的是模块 Roll 通道乘符号，`gyro_rad_s[1]` 是模块 Y 轴角速度，角与角速度不在同一根轴；Leg2 两者同取第 1 路且抬头为正。抬机头看 ch17/18 哪一路动、正负，只改 `lqr_balance.c` 顶部五个 `LQR_IMU_*` 宏并同步核对翻倒检测。右倾时调试器 `lqr_state.roll` 应为正（横滚 PID 方向依赖它）。架空只开轮通道、手转车体，两轮应出反向的阻转力矩，否则偏航环符号反了会自转。
  ①c 轮速腿摆补偿：架空推腿看 ch19，`vel_leg_comp_sign` 在 −1/+1 间切，取波动小的；按两边腿摆角定义相反推导，复现 Leg2 公式应为 +1。
  ①d 遥控转向方向：右摇杆推右车应右转；Leg2 对转向通道取了负号，本机没有，反了就在 `LQR_Target_Update()` 的 `axis_yaw` 上加负号。

② 手推倾斜看方向：前倾时 ch20/21 应为正。

③ `hip_enable=0`、`len_pid_enable=0`，只开轮，`trq_max_wheel` 从 0.5 N·m 起。

④ 开髋：给正 `u_BL`，足端应朝 +x 摆，左右腿同向。

⑤ 开腿长 PID：稳在目标腿长，两腿不打架。

⑥ 落地低速平衡，逐步抬 `trq_max_hip`，再加遥控。
```
