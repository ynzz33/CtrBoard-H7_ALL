# Vofa+ 调试发送模块

> 配合文件：[`Vofa_send.h`](../imcalib/user-lib/Vofa_send.h) 和 [`Vofa_send.c`](../imcalib/user-lib/Vofa_send.c)

---

## 1. 协议：FireWater

```
[float0][float1]...[floatN-1][0x00 0x00 0x80 0x7F]
  ↑ N × 4 字节 (小端)        ↑ 帧尾 (固定)
```

Vofa+ 通过帧尾 `0x00 0x00 0x80 0x7F` 识别一帧结束。

---

## 2. 使用方式

```c
/* 配置串口: 修改宏定义即可 */
#define VOFA_UART   &huart8
#define VOFA_MAX_CH 32   /* 最大通道数 */

/* 发送 */
float data[] = {1.0f, 2.0f, 3.0f};
Vofa_Send(data, 3);
```

---

## 3. 实现

```c
static const uint8_t tail[4] = {0x00, 0x00, 0x80, 0x7F};

void Vofa_Send(const float *data, uint8_t n)
{
    if (data == NULL || n == 0 || n > VOFA_MAX_CH) return;

    uint8_t buf[VOFA_MAX_CH * sizeof(float) + 4];
    uint16_t data_len = n * sizeof(float);

    memcpy(buf, data, data_len);
    memcpy(buf + data_len, tail, 4);

    HAL_UART_Transmit_DMA(VOFA_UART, buf, data_len + 4);
}
```

使用 DMA 发送，不阻塞 CPU。

---

## 4. 上位机配置

Vofa+ 设置：
- 协议：FireWater
- 串口：对应 COM 口
- 波特率：与 CubeMX 中 VOFA_UART 的波特率一致

---

## 5. 常量

| 常量 | 值 | 说明 |
|------|:--:|------|
| `VOFA_MAX_CH` | 32 | 最大通道数（上限） |
| `VOFA_PORT` | 8 | 发送串口编号：**8 = UART8（默认）/ 1 = USART1**；可用 `-DVOFA_PORT=n` 覆盖 |
| `VOFA_UART` | `&huart8` | 由 `VOFA_PORT` 推导 |

可选串口只有两个（都是 921600 + TX DMA NORMAL）：

| 口 | 状态 | 说明 |
|:--:|------|------|
| UART8 | 默认 | 当前 VOFA 口 |
| USART1 | 空闲 | 可直接切；CubeMX 已初始化且 DMA1_Stream6 已绑定 |

**不能选**：UART7（被 HI229 占用，且 TX DMA 是 CIRCULAR 模式）、UART9（被 DR16 占用，没有 TX DMA）。
填别的数字会在编译期报错（`#error VOFA_PORT ...`）。

## 当前 VOFA 通道布局（32 通道，上限 32）

发送频率：200Hz（commTask 1kHz，每 5 周期发一次）

| 通道 | 内容 | 单位 |
|:----:|------|:----:|
| 0 | 在线掩码（bit0=IMU, bit1=遥控, bit2~5=四台 DM 腿电机, bit6~7=两个轮 DJI） | - |
| 1 | 解算有效掩码（1=左腿, 2=右腿, **3=两腿都有效**） | - |
| 2 | 控制策略（0=手动遥操/RL, 1=LQR, 2=测试模式） | - |
| 3~8 | 虚拟关节**当前值** `get`：左大腿 / 左小腿 / 左轮 / 右大腿 / 右小腿 / 右轮 | rad 或 rad/s（轮是速度） |
| 9~14 | 虚拟关节**目标值** `set`：同上顺序 | 同上 |
| 15~20 | 虚拟关节 **PID 输出** `pos_out`：同上顺序 | Nm |
| 21~24 | 腿电机**下发力矩**：左前 / 左后 / 右前 / 右后 | Nm |
| 25~26 | **轮子下发力矩**：左轮 / 右轮 | Nm |
| 27~28 | 腿长：左 / 右 | m |
| 29 | 左小腿雅可比 `vshank_jac[0]`（→ 后髋电机） | - |
| 30 | 左小腿雅可比 `vshank_jac[1]`（→ 前髋电机） | - |
| 31 | 右小腿雅可比 `vshank_jac[0]`（→ 后髋电机） | - |

帧长：32×4+4 = **132 字节**；`VOFA_MAX_CH` = 32（上限，32 路全部使用）。

六个虚拟关节顺序 = `vj_all[6] = {0,1,2,3,4,5}` = 左大腿 / 左小腿 / 左轮 / 右大腿 / 右小腿 / 右轮，数据来源 `rl_control.torque_state.controller[]`。轮那一路的当前值/目标值是**速度**（rad/s），其余是角度（rad）。`pos_out` 是该路 PID 的输出（腿关节 = 虚拟力矩，轮 = 轮子力矩指令的源头）；因为 `ki = kd = 0`，`pos_out` 恒等于 P 项，误差为 0 时输出也为 0。

## 极性与坐标约定

右侧极性在驱动解码后统一到机体坐标系（`dm_sign[i].fb` / `dji_sign[i].fb`）；下发时按 `dm_sign[i].out` / `dji_sign[i].out` 在**驱动边界取反一次**，后续模块禁止重复取反。两份极性都在 `machine_config.c` 的机器表里，换机器只改表。

## sysid 独立数据帧（SYSID_ENABLE=1 时生效）

sysid 模式下**停发上面的32路调试帧**，改用独立帧（31列、500Hz、128字节/帧），走同一条 VOFA_UART。

- 入口：`imcalib/Sysid/sysid_log.c/h`（环形缓冲 + 组装 + DMA 发送泵）
- 采集：`imcalib/Sysid/sysid_mode.c` 的 `Sysid_Mode_Run()` 在每个500Hz控制周期快照并推入缓冲
- 发送：`comm_task_body()` 调用 `Sysid_Log_Send_Pump()`，1kHz调用、2分频→500Hz实际发送
- 帧格式：JustFloat，31列固定列宽，列定义见 `sysid_log.h` 头部注释
- 列布局汇总见 `md/sysid-lower-machine-plan.md` §7.2
